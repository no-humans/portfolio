# Design System

## Direction

Premium, minimal, editorial, modern, spacious and typography-driven.

Avoid:
- glassmorphism
- neon
- excessive gradients
- 3D/WebGL
- generic SaaS styling
- excessive rounded cards
- constant motion

## Theme

Strict light theme.

```css
--color-bg: #FFFFFF;
--color-surface: #FFFFFF;
--color-surface-muted: #F8F8F8;
--color-text-primary: #0A0A0A;
--color-text-secondary: #4A4A4A;
--color-text-muted: #777777;
--color-border: #E5E5E5;
--color-border-strong: #CFCFCF;
--color-accent: #FF5A00;
--color-accent-hover: #E94F00;
--color-black: #000000;
--color-white: #FFFFFF;
```

## Orange

Use only as an accent:
- `P.` in PRANAV P.
- section numbers
- active nav indicator
- DEVELOPER
- labels
- decorative lines
- timeline dots
- arrows
- hover indicators
- progress indicators

Do not use large orange surfaces or orange gradients.

## Container

```css
max-width: 1440px;
margin-inline: auto;
```

Horizontal padding:
- Mobile 20px
- Tablet 32px
- Laptop 48px
- Desktop 64px
- Large desktop 80px

## Borders

Use thin, subtle borders.

## Radius

Keep an editorial/sharp character. Normal cards should generally use 2–8px radius, not pill shapes.
