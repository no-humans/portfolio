# Typography

## Font

Use one modern geometric/neo-grotesk sans-serif.

Preferred:
1. Inter
2. Geist
3. Manrope
4. comparable high-quality free sans-serif

## Hero

`LET'S TALK` is the strongest typographic element.

Starting direction:

```css
font-size: clamp(5rem, 9vw, 10rem);
font-weight: 700;
line-height: 0.82–0.92;
letter-spacing: -0.05em;
```

Tune against the reference.

## Section headings

```css
font-size: clamp(2rem, 3vw, 4rem);
font-weight: 700–800;
```

## Body

16–18px, line-height around 1.6.

## Metadata

11–13px, uppercase, letter-spacing 0.04–0.1em.

Keep typography readable on mobile.
